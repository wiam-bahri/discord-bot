# Wiam.dev Bot

## الميزات
- 👋 رسالة ترحيب في قناة الترحيب + رسالة خاصة (DM) تلقائية لكل عضو جديد
- 🔗 القائمة الرئيسية: **من هي وئام** و **تابعوني**
- 🎥 **أخبار وئام**: إعلان تلقائي عند نزول فيديو جديد على يوتيوب
- 🔒 اللوحة الإدارية: **إرسال رسالة** فقط

## التشغيل
```
pip install -r requirements.txt
```
انسخ `.env.example` إلى `.env` وضع فيه التوكن و GUILD_ID، ثم:
```
python main.py
```
كل الإعدادات (القنوات، النصوص، الروابط) في `config.py`.
